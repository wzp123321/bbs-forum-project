## P1 收尾 + 三项功能 + 上传鉴权（20:30）

**归档**：`user-profile-and-notification`（P1）与本次两个变更（`fix-attachment-auth`、`follow-draft-password`）均已 archive，specs 增至 10 份。P1 端到端实测：admin 点赞 alice 帖子 → 未读 0→1、取消点赞通知删除、自己赞自己不通知。

**附件上传是真坏的，不只是「免登录」**：`WebMvcConfig` 把 `/admin/attachment/**` 整体排除，拦截器不跑 → `AuthContext` 空 → 登录用户上传也 401。改为只放行 `upload.url-prefix`（`/upload/**`），实测带 token 200、无 token 401、静态资源匿名 200。

**新功能**
- 关注流 `post/followFeed`：`EXISTS` 子查询 + `status=1` + 排除自己，首页加「关注」tab（登录可见）。

**坑**

## 两个遗留一次性收掉（21:00）

**参数校验**：pom 补 `spring-boot-starter-validation`，全站 `@Valid` 生效。`GlobalExceptionHandler` 早有校验处理器且返回 `R.fail(400, msg)`（HTTP 200），前端不用改——若返回 HTTP 400，axios 会 reject 并丢中文提示。删掉 resetPassword 的手动长度兜底。实测空登录体 / 空标题 / 超长板块名 / 短密码均 `code=400` + 中文字段提示，合法发帖评论 200。
